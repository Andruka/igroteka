Первый выпуск по [аудиту проекта](PROJECT_AUDIT.md), 13 ноября 2026 года.

Сделаны пункты 1–5 и небольшие исправления из пунктов 13 и 15. Обновлён общий интерфейс всех игр; механики и базы заданий сохранены.

| Изменение | Результат |
|---|---|
| Диалоги | Есть закрытие даже у информационных окон без заданных кнопок. Escape отменяет действие. Tab остаётся внутри окна, фон недоступен, фокус возвращается после закрытия. Вложенные окна поддерживаются |
| Жалобы | При переходе в другую игру активная карточка очищается. Жалоба сохраняет снимок выбранной карточки, даже если таймер сменил её. «Табу» учитывает текущее слово, а не начало раунда |
| «Пары» | Жаловаться можно только на открытые карточки. Несколько видимых пар выбираются из списка; закрытые через него не раскрываются |
| Каталог | Поиск и число игроков видны сразу. Темы и категории свёрнуты. Есть общий сброс условий, понятное пустое состояние и отключение случайного выбора при пустом результате |
| Люди и команды | Для фильтра используется отдельное описание числа людей. Компания из четырёх видит «Кодовые имена», а настройка партии по-прежнему содержит две команды |
| Выбор режима | «Один» запускает одиночный режим; «2» выбирает дуэт у игр, которые его поддерживают. В дуэте два игрока, лишние командные настройки скрыты |
| Запуск | Кнопка «Играть» находится перед подробными параметрами. Правила и имена раскрываются отдельно. Длинные списки тем заменены компактным выбором |
| Подписи и счётчики | У одиночного режима имя «Игрок 1». Исправлен знак штрафа подсказки нонограмм. Каталог сообщает число игр без повторного суммирования общей базы викторины |

На сенсорной эмуляции 375×667 первая карточка каталога теперь начинается примерно на 330 px вместо 910 px. Кнопка запуска «Пар» начинается примерно на 312 px вместо 3850 px. Это измерения расположения элементов, а не оценка поведения реальных игроков.

Проверки:

- `npm run test:release` — каталог, выбор людей и режимов, первый экран всех 47 игр, настройки, жалобы и клавиатура диалогов; размеры 360×640, 375×667 и 1440×900.
- `npm run test:menu` — запуск, выход в меню, результаты и повторный запуск всех игр.
- `npm run test:memory` — данные, одиночная и командная механика, вместимость полей на четырёх размерах, уменьшенная анимация.
- `node test/fav.js` — избранное и его фильтр.
- `node test/duet.js` — дуэты «Крокодила», «Табу» и рисования, очки и рекорды.
- `node test/codenames_duet.js` — дуэт и обычный режим «Кодовых имён».

Общая пауза, инструменты проверки карточек и сохранение партии добавлены во [втором выпуске](RELEASE_2.md). Короткие обучающие партии, общие рекорды и новые режимы остаются следующими этапами.
