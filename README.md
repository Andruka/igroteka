# Игротека

Игры для компании на одном экране: поставьте ноутбук или телевизор на стол — телефоны и интернет не нужны.
30 игр, около 5400 карточек, которые не повторяются, пока не закончатся все.

**Играть:** https://andruka.github.io/igroteka/

## Игры
Викторины: «Выбери тему», «Эмодзи-кино», «Найди фейк», «Пять подсказок», «Найди лишнее», «Что раньше?», «Больше или меньше».
Для компании: «Дилеммы», «Без концовки», «Правда или действие», «Кто скорее всего…», «Я никогда не…», «Верю — не верю», «Секретные задания», «Горячая бомба», «Шпион».
Командные: «Кино с подвохом», «Дословно», «Крокодил», «Табу», «Кто я?».
Кооперативные: «Ночное дело», «Эфир до рассвета», «Комната на время», «Обезвредить».

**Новое:** «Своя игра» (табло), «Рисуем и угадываем» (холст на общем экране), «Виселица», «Ассоциации», «Города»;
«Тема вечера» (Новый год, День рождения, Для детей, Корпоратив, Для друзей); выбор нескольких категорий в играх;
настройки звука, музыки, озвучки вопросов (встроенный голос браузера) и эффектов; кнопка-флажок «Ошибка в карточке».

На главной можно отфильтровать игры по числу игроков или нажать «Случайная игра». В каждой командной игре сверху видно, чей сейчас ход и что нужно делать.

## Запуск без сервера
Скачайте `index.html` и откройте двойным кликом. Это один самодостаточный файл: шрифты, картинки и данные внутри.

## Сборка из исходников
```
python3 build.py        # собирает index.html из src/
node test/bot.js all    # прогон всех игр случайными кликами (нужен playwright)
```
- `src/engine.js`, `src/kit.js` — движок и общие компоненты
- `src/games/` — по файлу на игру; `src/data/` — карточки и словарь иллюстраций
- `src/*.css` — оформление; `src/fonts.css` генерирует `tools/make_fonts.py` (Inter, лицензия OFL)

Иллюстрации подбираются по смыслу текста вопроса из словаря эмодзи (`src/data/d_pics.js`).

## Иллюстрации
Обложки игр — иллюстрации [Icons8 Ouch](https://icons8.com/illustrations), стиль Bouncy (бесплатное распространение), SVG встроены в `index.html`. Оригиналы лежат в `art/`.
