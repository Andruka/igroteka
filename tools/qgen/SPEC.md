# Спецификация генерации вопросов викторины

Формат: JSONL, одна строка = один вопрос: {"q":"...","a":"верный","w":["неверный1","неверный2","неверный3"]}
Без markdown, без комментариев, ровно одна JSON-строка на вопрос, русский язык.

## Шкала сложности (доля образованных взрослых россиян, ответивших верно БЕЗ вариантов)
1 Лёгкий ≈ 85–95%  — знает почти каждый (школа, повседневность).
2 Средний ≈ 55–70% — знает большинство увлечённых людей.
3 Сложный ≈ 30–45% — нужно специально интересоваться темой.
4 Эксперт ≈ 12–22% — знают энтузиасты/профессионалы темы.
5 Гроссмейстер ≈ 3–8% — узкие детали; всё равно однозначный проверяемый ответ.
Сложность одинакова во всех категориях: «Эксперт» по еде = «Эксперт» по науке по доле знающих. Не завышай сложность запутанной формулировкой — повышай её глубиной знания.

## Правила качества
- Только устойчивые, проверяемые факты (энциклопедии, учебники). Никаких «самый/первый», если есть спор; никаких свежих данных, которые устаревают (население, рекорды, действующие чемпионы) — только с годом в вопросе.
- Один однозначный верный ответ. Неверные варианты правдоподобны, того же типа и формата (годы рядом, города той же страны), НЕ абсурдные, и ни один неверный не может оказаться тоже верным.
- Не подсказывай ответ в формулировке; верный не самый длинный и не единственный «непохожий».
- Вопросы разнообразны по подтемам, без повторов и без вариаций одного факта. Не ставь имя ответа в вопрос.
- Взрослая аудитория, без детских и глупых вопросов; без политической агитации и оценочных суждений.
- Если не уверен в факте на 99% — не включай.
