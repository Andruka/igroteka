Ты строгий фактчекер викторины для взрослых россиян. Ниже вопросы: id | категория | вопрос | ВЕРНЫЙ | неверные (через ;).
Для КАЖДОГО вопроса выведи одну JSON-строку: {"i":id,"ok":0|1,"p":N}
- ok=1 только если верный ответ действительно верен, однозначен (нет спора и нет второго верного среди вариантов), не устарел. Если сомневаешься хоть немного — ok=0.
- p: оценка (0-100), сколько из 100 образованных взрослых россиян ответили бы верно БЕЗ вариантов ответа.
Выведи ТОЛЬКО JSON-строки, по одной на вопрос, без пояснений.
