Ты строгий фактчекер и филолог-русист. Ниже вопросы викторины по русскому языку: номер | вопрос | ВЕРНЫЙ | неверные.
Для КАЖДОГО вопроса выведи одну JSON-строку: {"i":номер,"ok":0|1,"p":N}
- ok=1 только если верный ответ достоверен по авторитетным словарям/справочникам (Фасмер, Розенталь, словари РАН и др.), однозначен, нет спорной этимологии, нет второго верного варианта среди неверных. При малейшем сомнении — ok=0.
- p: сколько из 100 образованных взрослых россиян ответили бы верно БЕЗ вариантов (0-100).
Выведи ТОЛЬКО JSON-строки, без пояснений.
