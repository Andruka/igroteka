# Игротека — контекст для Claude

Офлайн-сайт с party-играми на русском для компании на одном экране (ноутбук/ТВ/телефон).
Публикуется на GitHub Pages: https://andruka.github.io/igroteka/ (раздаётся собранный `index.html`).

## Сборка
- `python3 build.py` собирает **один самодостаточный `index.html`** (без внешних зависимостей, работает офлайн двойным кликом). Собранный файл коммитим.
- Порядок CSS: fonts, base, games, polish.
- Порядок JS: `engine.js`, `audio.js`, `kit.js`, `pics.js`, `src/data/*.js` (по алфавиту), `src/games/*.js` (по алфавиту), затем `boot()`. Всё в одном script-scope с `'use strict'`.
- `d_xhard.js` обязан идти после `d_hl.js` (использует `_H`) — учитывай порядок имён.
- Идентификатор `E` занят. CSS-класс `.empty` глобальный — не переиспользовать.

## Архитектура
- Игра — файл `src/games/gNN_name.js` с вызовом `registerGame({id,title,icon,color,cats,teams:{min,max},mins,tagline,rules,opts,cards,start(api)})`.
- В `api`: `show, setTurn, score, pickTeam, end, teams, n, opts`.
- Хелперы: `makeDeck, levelDeck, judgeRow, handover, Timer, modal, btn, h, shuffle, rnd, sfx, fx, Pics, store`.
- Вопросы викторины: `Q(cat, level 1–5, вопрос, верный, неверный1, неверный2, неверный3)` в `src/data/d_quiz*.js`. Уровни: Лёгкий, Средний, Сложный, Эксперт, Гроссмейстер.
- Обложки игр — Icons8 Ouch (Bouncy), оригиналы в `art/`.

## Тесты (`npm i playwright && npx playwright install chromium`)
- Браузер: по умолчанию стандартный playwright chromium; можно задать `CHROMIUM_PATH=/путь/к/chrome`.
- `node test/bot.js all 60` — случайные клики по всем играм; `node test/levels.js` — уровни сложности.
- `node test/touch.js` — защита от выделения на телефонах.
- `node test/layout.js all <w> <h>` на 375×667, 768×1024, 1280×720, 1920×1080.
- Для каждой новой игры добавлять свой тест в `test/`.

## Правила
- Игры требуют только устройство с сайтом: никаких «просто поговорить» игр без механики (Ассоциации и Города удалены сознательно).
- Аудитория — взрослые; не детские и не глупые игры.
- Фактическая точность вопросов важна: никаких сомнительных/устаревших фактов, проверять по надёжным источникам.
- Выделение текста/элементов пальцем на телефонах отключено осознанно (`polish.css`, защита в `engine.js`) — не ломать.
- После каждого изменения: `python3 build.py`, соответствующие тесты, нет ошибок в консоли.
- Коммиты небольшие, осмысленные, на русском; собранный `index.html` коммитим.
