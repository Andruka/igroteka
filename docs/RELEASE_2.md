Второй выпуск по [аудиту проекта](PROJECT_AUDIT.md), 13 ноября 2026 года.

Реализованы общая пауза, инструменты проверки карточек с первыми исправлениями и сохранение партии для трёх игр — пункты 6–8 плана.

Пауза:

- Кнопка «Пауза» находится в баннере хода. Правила, настройки, жалоба и окно выхода также останавливают игровое время.
- Вложенные окна не возобновляют отсчёт, пока последнее из них не закрыто.
- Отложенные ходы компьютера, запал «Горячей бомбы» и обработка открытой пары используют то же время.
- При скрытии вкладки время останавливается. После возвращения открывается окно паузы; продолжение требует действия игрока.
- При уходе из сессии ожидающие игровые действия отменяются и не могут вернуть старый экран.

Сохранения:

| Игра | Что восстанавливается |
|---|---|
| «Пары» | Порядок поля, найденные и открытые карточки, владельцы пар, очки, очередь, попытки и остаток ожидания после открытия двух карточек |
| «Японские кроссворды» | Та же картинка, заполнение и крестики, подсказанные клетки, история отмены, режим кисти, время и штрафы |
| «Взлом кода» | Тот же секрет, попытки, незавершённый ввод, выбранная позиция, таймер, текущий раунд, очередь и очки |

Состояние сохраняется после действий и периодически во время партии, а также перед уходом со страницы. Кнопки «Продолжить» доступны в каталоге и меню игры. Можно удалить сохранение или начать новую партию. В превью нет секретных данных. Сохранения находятся в браузере на этом устройстве. [Каталог с сохранениями](audit/release2-continue-mobile.png), [пауза на телефоне](audit/release2-pause-mobile.png).

Чтение проверяет версию, параметры игры и структуру состояния. Повреждённое или несовместимое сохранение получает понятное сообщение и кнопку удаления. Ошибка записи не прерывает игру и показывается игроку. Завершённые партии очищаются; восстановление выигранного раунда не начисляет очки повторно.

Карточки:

- Добавлена [проверка данных](../tools/check_cards.js), команда `npm run check:data` и [памятка для редактора](CARD_REVIEW.md).
- Вопросы викторины получили устойчивые ID; история показа не зависит от перестановки элементов массива. Прежняя числовая история начинает новый цикл один раз.
- Убраны два повтора: про шафран и оксюморон. Сохранены вопросы с меньшей сложностью.
- Вопрос о рекорде НХЛ привязан к событию 6 апреля 2025 года; добавлены источник, дата проверки и объяснение. В викторине объяснение показывается после ответа.
- В базе 8443 вопроса и 2553 пары в 49 темах. Один вопрос имеет полный редакторский статус, остальные не объявляются проверенными по фактам.
- Если после скрытия карточек в теме «Пар» не хватает материала для поля, игра предлагает сменить тему или размер, вместо выдачи повторяющихся пар.

Проверки:

- `npm run test:session` — ручная и автоматическая пауза, вложенные окна, скрытие вкладки, компьютер и бомба; перезагрузка и завершение трёх сохранённых игр; повреждения, версии, нехватка памяти и доступных пар.
- `npm run test:cards` — текущая база и примеры дефектных карточек, сохранение значимых символов, ID и даты.
- `npm run test:release`, `npm run test:menu` — каталог, старт и возврат в меню всех 47 игр.
- `npm run test:memory`, `npm run test:nonogram`, `npm run test:codebreaker` — прежние сценарии трёх игр, в том числе поле и управление на разных экранах.
- `npm run test:norepeat` — отсутствие повторов, перестановка карточек и совместимость прежних скрытых вопросов.
- Дополнительно проверены дуэты и тематические наборы, жалобы, озвучка и сохранение настроек.

`npm run check` запускает сборку и перечисленные основные проверки одной командой. Полная фактологическая редактура оставшейся базы, сохранение остальных игр и проверки в других браузерах остаются отдельной работой.
